# Abstract

Chest radiography is the most common first-line imaging test for lung disease, but reading it is slow where radiologists are scarce. Deep learning models can classify chest X-rays, yet many published systems report accuracy on test sets that share patients, sources or labelling shortcuts with the training data, so their reported performance does not describe how they behave on a new hospital's images. This project builds LungAI, a six-class chest X-ray classifier (COVID-19, Normal, Pleural Effusion, Pneumonia, Pulmonary Nodule / Mass, Tuberculosis) and, more importantly, an auditable and leakage-controlled pipeline around it.

An earlier version of the system (V5) recorded 82.93% internal accuracy. An audit found that 154 of its 1,570 test images (9.8%) shared a patient with the training set, that half of its Pneumonia class consisted of proxy labels, and that on an external hospital cohort it labelled none of 80 normal scans as normal (specificity 0/80). Its checkpoint is lost, and its numbers are reported here only as history. The present work (V6) rebuilds the dataset from the official distribution points of NIH ChestX-ray14, Kermany, Shenzhen, Montgomery, the Cohen COVID-19 collection, TBX11K and the COVID-19 Radiography Database, with label rules fixed before training, per-source caps, content hashes for every image, and a split by patient group in which exact and near-duplicate images are merged into one group. Leakage checks (groups spanning splits, identical files spanning splits, external images in development data) all evaluate to zero. The Montgomery County set is kept as an external cohort that is never used for training or model selection.

The classifier is a DenseNet-121 initialised with ImageNet weights, with a global-average-pooling head, a 256-unit layer and a six-way softmax. Images are processed by a fixed chain of Gaussian blur, CLAHE on the luminance channel, a Gaussian low-pass filter and resizing to 224 × 224. Training is a two-phase schedule (frozen backbone, then fine-tuning of the last 30 layers) with class-balanced weights, a single seed (42), on a laptop CPU within a wall-clock budget. The model is served by a FastAPI backend with a heuristic chest X-ray input gate, Grad-CAM overlays and an SQLite store, and by a React frontend that shows the scores, the explanation and the evaluation metrics of the exact checkpoint in use.

Internally the weakest classes are Pulmonary Nodule / Mass (F1 {{FOneNodule}}%) and Normal (F1 {{FOneNormal}}%), whose labels in the NIH collection are mined from reports. A source-identifiability probe shows that the source of an image can be predicted from the model's features with a balanced accuracy of {{ProbeMdlBalAcc}}% (chance {{ProbeMdlChance}}%), and the Grad-CAM examples for COVID-19 and Normal fall outside the lung fields; together with the external behaviour this is indirect evidence that source cues are available to the classifier, not proof that it uses them. The final model was chosen over the first V6 run by a rule fixed before the second run's results were seen, and much of its advantage lies on sources that only it was trained on. The main contributions are an auditable rebuild of a multi-source six-class benchmark from official sources; a reproducible pipeline from acquisition through patient-grouped splitting, training and once-only test and external evaluation to the metrics served by the application; evidence that internal metrics overstate generalisation; and an audit documenting how the earlier pipeline's leakage inflated its results. The system is a research prototype and is not clinically validated. Each result comes from one training run per model, so differences of a few points should not be read as evidence that one model is better.
