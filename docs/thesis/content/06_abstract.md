# Abstract

Chest radiography is the most common first-line imaging test for lung disease, but radiologists are scarce in many places. Deep learning models can classify chest X-rays (CXR), yet some published systems are tested on data that share patients or sources with their training set. This project builds LungAI, a six-class CXR classifier (COVID-19, Normal, Pleural Effusion, Pneumonia, Pulmonary Nodule / Mass, Tuberculosis) and an auditable, leakage-controlled pipeline around it.

An earlier version (V5) recorded 82.93% internal accuracy. An audit found that 154 of its 1,570 test images (9.8%) shared a patient with the training set, that half of its Pneumonia class consisted of proxy labels, and that on an external cohort it labelled none of 80 normal scans as normal. The present work (V6) rebuilds the dataset from the official sources of seven collections. Label rules were fixed before training, and the split is by patient group, with near-duplicates placed in the same group. All leakage checks evaluate to zero, but patient separation is proven only for rows with known patient identity: TBX11K and COVID-19 Radiography rows are grouped per image. The Montgomery County set is the external cohort. It was never used for training or checkpoint selection, but the second V6 run was started after the first run's external results were seen.

The classifier is a DenseNet-121 with ImageNet weights, a global-average-pooling head and a six-way softmax, trained in two phases on a laptop CPU (served seed 42) after a fixed preprocessing chain (blur, CLAHE, low-pass filter, resizing to 224 × 224). It is served by a FastAPI backend (input gate, Grad-CAM) and a React frontend.

The final model is {{ModelVersion}} (build {{DatasetBuild}}), trained on {{NTrain}} images and evaluated once on {{NTest}} internal test images and {{NExternal}} external images. Internal test accuracy is {{TestAcc}}% (Wilson 95% interval {{TestAccLo}}% to {{TestAccHi}}%), macro F1 {{TestMacroFOne}}%, macro ROC-AUC {{TestMacroAUC}}. Externally, {{ExtSensK}} of {{ExtSensN}} tuberculosis scans were flagged abnormal, but only {{ExtSpecK}} of {{ExtSpecN}} normal scans were called Normal and {{ExtTBK}} of {{ExtTBN}} tuberculosis scans were named Tuberculosis. The internal result therefore overstates behaviour at an unseen hospital. The source of an image can be predicted from the model's features (balanced accuracy {{ProbeMdlBalAcc}}%, chance {{ProbeMdlChance}}%) and some Grad-CAM examples fall outside the lung fields. This is indirect evidence that source cues are available; it does not show that the model uses them. A rule written down before the second run's results existed chose the final model over the first V6 run. Over three seeds of the same recipe and split, test accuracy is {{MSTestAccMean}} ± {{MSTestAccSD}}% (mean ± SD) and the external failure recurs in every seed. In one ablation run at the same seed, removing the preprocessing filters lowered test accuracy to {{AblTestAcc}}% and left external specificity unchanged.

The contributions are an auditable rebuild, a reproducible pipeline, evidence that internal metrics overstate generalisation, and an audit of the earlier pipeline. The system is a research prototype, not clinically validated, and the ablation is a single run.

**Keywords:** chest X-ray, DenseNet-121, transfer learning, Grad-CAM, patient-grouped split, data leakage, external validation, FastAPI.
