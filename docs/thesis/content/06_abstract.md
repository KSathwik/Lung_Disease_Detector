# Abstract

Chest radiography is the most common first-line imaging test for lung disease, but radiologists are scarce in many places. This project designs and develops LungAI, a deep learning system that predicts one of six classes from a frontal chest X-ray (CXR): COVID-19, Normal, Pleural Effusion, Pneumonia, Pulmonary Nodule / Mass or Tuberculosis.

The system has three parts. The first is a data pipeline that downloads seven public collections from their official sources, applies label rules fixed before training, detects duplicates and splits the images by patient group into training, validation and test sets. Six collections form the development data and the Montgomery County set is kept apart as an external cohort. Patient separation is proven only for rows with known patient identity: TBX11K and COVID-19 Radiography rows are grouped per image. The second part is the classifier, a DenseNet-121 with ImageNet weights, a global-average-pooling head and a six-way softmax, trained in two phases on a laptop CPU after a fixed preprocessing chain (blur, CLAHE, low-pass filter, resizing to 224 × 224). The third part is a web application. A FastAPI backend checks that the uploaded image looks like a chest radiograph, runs the classifier, computes a Grad-CAM overlay, marks low-confidence predictions as inconclusive and stores each result in a database. A React frontend shows the six scores, the overlay, the prediction history, patient records and the evaluation metrics of the loaded model. The application loads a checkpoint only if its hash matches the configuration and returns an error, never a placeholder prediction, when no verified model is available.

The final model is {{ModelVersion}} (build {{DatasetBuild}}), trained on {{NTrain}} images and evaluated once on {{NTest}} internal test images and {{NExternal}} external images. Internal test accuracy is {{TestAcc}}% (Wilson 95% interval {{TestAccLo}}% to {{TestAccHi}}%), macro F1 {{TestMacroFOne}}%, macro ROC-AUC {{TestMacroAUC}}. Over three seeds of the same recipe and split, test accuracy is {{MSTestAccMean}} ± {{MSTestAccSD}}% (mean ± SD). In one ablation run at the same seed, removing the preprocessing filters lowered test accuracy to {{AblTestAcc}}%. On the external cohort, {{ExtSensK}} of {{ExtSensN}} tuberculosis scans were flagged abnormal, but only {{ExtSpecK}} of {{ExtSpecN}} normal scans were called Normal and {{ExtTBK}} of {{ExtTBN}} tuberculosis scans were named Tuberculosis, and this external weakness recurs in every seed. The system therefore classifies well within its development data and does not yet transfer to an unseen hospital. The application reports this limitation with every prediction.

The system is the second version of the project. An earlier version was audited, its data faults were documented, and the data pipeline was rebuilt (Appendix E). Supplementary measurements on frozen features, which examine how far the source of an image can be predicted from the features, are reported in Appendix G; they are indirect and do not show that the model uses the source.

The contributions are the design of an end-to-end CXR prediction system, its implementation as a tested web application with input checking, visual explanation and safeguards, and an evaluation that reports internal, multi-seed and external behaviour together with the limitations. The system is a research prototype and is not clinically validated.

**Keywords:** lung disease detection, chest X-ray, deep learning, DenseNet-121, transfer learning, Grad-CAM, FastAPI, React, external validation.
