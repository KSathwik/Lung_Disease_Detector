\section{Conclusion}
\label{sec:conclusion}

We rebuilt a multi-source, six-class chest radiograph benchmark from official sources, with labelling rules fixed before training, per-file provenance, patient- and near-duplicate-grouped splits, recorded leakage checks and a held-out external hospital cohort, and trained a standard DenseNet-121 on it. The selected model reached an internal test accuracy of \RTestAcc\% (95\% CI \RTestAccLo--\RTestAccHi\%) and macro ROC-AUC \RTestMacroAUC; on the external cohort it flagged \RExtSensK/\RExtSensN{} TB radiographs as abnormal, called \RExtSpecK/\RExtSpecN{} normal radiographs Normal, and named \RExtTBK/\RExtTBN{} TB radiographs Tuberculosis. Leakage control was necessary but not sufficient: the internal results substantially overstated the model's behaviour on an unseen hospital. Class and source are strongly confounded in these public collections, and the source of an image is linearly recoverable from the features the classifier uses, which makes a source shortcut plausible, although our evidence for it is indirect. Adding a second source for COVID-19 and Tuberculosis largely removed one apparent source effect (COVID-19 predictions on the external cohort) but moved the external errors to other abnormal classes instead of closing the gap. These are observations from single training runs; \pending{seed variability and ablation: one sentence on whether the seed spread (runs 3--4) or the no-filter run (run 5) changes any of these conclusions}.

An audit of the earlier pipeline showed how patient leakage, proxy labels and reporting sensitivity without specificity can turn a weak model into an apparently strong one, and a measurement of the deployed input gate showed that a component outside the classifier can silently reject most genuine inputs. Multi-source chest radiograph benchmarks should at minimum document provenance, fix label rules in advance, group splits by patient and content, report results per source, and evaluate on an unseen hospital with sensitivity and specificity together. The main results come from a single training run per build and carry no claim of clinical validity.
