# Figures

All figures are generated by `lungai/evaluation/make_figures.py` (PNG at 300 dpi plus vector PDF, same stem).
Numbers are read from artifacts; only labels are typed in the script.

Command (run from the repository root; needs matplotlib, numpy, pandas, scikit-learn, opencv; TensorFlow is not imported):

    python -m lungai.evaluation.make_figures --eval-prefix v6 --run runs/v6_densenet121_seed42 --build data/derived/v6_build_001

Options: `--only <stem> ...` builds a subset. `--gradcam` is a stub for `fig_gradcam_examples` and raises `NotImplementedError("run after final model selection")`.
Note: on this machine the Python 3.10 install has matplotlib; the 3.12 install does not.

Common inputs: `lungai/configs/lungai_densenet121.json` (class order, architecture, preprocessing). EP = `artifacts/evaluation_reports/<prefix>_{val,test,external}/`.

| Stem | Inputs | Suggested caption (result-neutral) |
|---|---|---|
| fig_pipeline | none (static diagram) | End-to-end pipeline: acquisition from official sources, dataset build with patient-grouped splitting and leakage checks, training, once-only test and external evaluation, served metrics, and the application. |
| fig_system_architecture | none (diagram; matches docs/architecture.md and backend) | System architecture: React frontend, FastAPI backend with routes, two-stage CXR gate, inference engine, Grad-CAM, SQLite store, model store and the served metrics file. |
| fig_dataflow | none (diagram; matches backend/api/routes/predictions.py) | Data flow of one prediction request from upload to response; rejected inputs return an HTTP error with a reason. |
| fig_model_architecture | config JSON; `runs/<run>/run_metadata.json` (phase settings) | DenseNet-121 backbone with global average pooling, batch normalisation, Dense(256), Dropout(0.3) and a six-way softmax, trained in a head phase followed by a fine-tuning phase. |
| fig_preprocessing | manifest (one Shenzhen test image), `data/raw/`, `lungai.preprocessing` | One radiograph after each preprocessing step: Gaussian blur, CLAHE on the LAB lightness channel, Gaussian low-pass and Lanczos resize. Image: Shenzhen CXR set (NLM), Jaeger et al. 2014. |
| fig_dataset_composition | `<build>/manifest_v6.csv` | Images per class and source in the training, validation, test and external sets of the final build. |
| fig_training_curves | `run_metadata.json` history | Training loss (a) and validation accuracy, macro-F1 and macro ROC-AUC (b) per epoch; the dashed line marks the start of fine-tuning and the star the selected epoch. |
| fig_confusion_matrix | EP test `metrics_test.json` | Test-set confusion matrix as counts (a) and row-normalised (b). |
| fig_roc_curves | EP test `predictions_test.csv` | One-versus-rest ROC curves per class on the test set, with AUC in the legend. |
| fig_per_class_metrics | EP test `metrics_test.json` | Per-class precision, recall and F1 on the test set; error bars are 95% Wilson intervals for recall. |
| fig_per_source | EP test `metrics_test.json` (per_source) | Test accuracy by source dataset with 95% Wilson intervals; the dashed line is overall accuracy. |
| fig_external_breakdown | EP external `metrics_external.json` (prediction_breakdown) | Predicted class for Montgomery normal and tuberculosis scans (external cohort). Report sensitivity only together with specificity. |
| fig_calibration | EP test `metrics_test.json` (calibration bins) | Reliability diagram on the test set (a) with the number of images per confidence bin (below); ECE in the legend. |
| fig_gradcam_examples | not generated yet | Grad-CAM overlays on selected test images (to be produced after final model selection). |

Result-dependent figures (dataset composition, training curves, confusion matrix, ROC, per-class, per-source, external, calibration) must be regenerated for the final model by re-running the command with the final `--eval-prefix`, `--run` and `--build`.
